Heads up. Flashing replaces everything on the board, including your pet's saved stage and XP. The install dialog offers an erase option on first install; leaving it unchecked keeps the existing filesystem where the board layout allows it.
Prefer the command line? Every image is a merged binary, flashable at offset 0x0:
esptool.py --chip esp32s3 --port <PORT> --baud 921600 write_flash 0x0 <image>.bin
Use --chip esp32c5 for the T-Dongle C5. After flashing, power-cycle the board — an esptool reset alone can leave it in download mode.
