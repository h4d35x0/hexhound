# HexHound

### Cyber Recon Pet System for LilyGo T-Dongle S3

---

# 1. Project Overview

HexHound is a **gamified cybersecurity companion device** built on the LilyGo T-Dongle S3 (ESP32-S3).

The device acts as a **digital pet that evolves through stages**, gaining abilities as it gathers information from its environment and completes safe training missions.

The pet combines three functional roles:

| Role         | Function                             |
| ------------ | ------------------------------------ |
| Recon Pet    | discovers networks and BLE devices   |
| USB Gremlin  | performs harmless awareness missions |
| Guardian Pet | detects suspicious activity          |

The pet grows based on **real-world environmental interactions**.

---

# 2. Core Goals

The system is designed to:

* Gamify cybersecurity awareness
* Provide lightweight environmental reconnaissance
* Demonstrate security concepts visually
* Create a portable demo device
* Provide educational alerts

---

# 3. Hardware Platform

The device is built around **LilyGo T-Dongle S3**.

Typical board features include:

| Component                  | Function         |
| -------------------------- | ---------------- |
| ESP32-S3 dual-core 240 MHz | main processor   |
| Wi-Fi 2.4 GHz              | network scanning |
| Bluetooth BLE              | beacon scanning  |
| ST7735 LCD display         | UI               |
| RGB LED                    | alerts           |
| USB-A connector            | power + USB HID  |
| MicroSD / TF slot          | logs             |
| Button                     | input            |

ESP32-S3 supports **native USB HID functionality** via TinyUSB and includes integrated Wi-Fi and Bluetooth radios suitable for scanning tasks (Espressif Systems, n.d.-a; Espressif Systems, n.d.-b).

---

# 4. Pet Evolution System

The pet evolves through **five stages**.

| Stage | Name               | Ability              |
| ----- | ------------------ | -------------------- |
| 1     | Egg                | initialization       |
| 2     | Packet Pup         | Wi-Fi reconnaissance |
| 3     | Beacon Beast       | BLE detection        |
| 4     | Gremlin Mode       | USB missions         |
| 5     | Sentinel | anomaly detection    |

---

# 5. Stage Behavior

## Stage 1 - Egg

State when device is first flashed.

Characteristics:

* sleeping animation
* minimal abilities
* gathers initial interactions

Requirements to hatch:

* 10 interaction points
* 1 Wi-Fi scan
* 1 USB connect
* first save file created

---

## Stage 2 - Packet Pup

Wi-Fi recon stage.

Abilities:

* Wi-Fi scanning
* channel analysis
* SSID logging

Food sources:

| Event          | Food | XP |
| -------------- | ---- | -- |
| Wi-Fi network  | 5    | 2  |
| trusted SSID   | 10   | 3  |
| scan completed | 3    | 1  |

---

## Stage 3 - Beacon Beast

BLE detection stage.

Abilities:

* BLE scanning
* tracker detection
* beacon logging

Food sources:

| Event             | Food | XP |
| ----------------- | ---- | -- |
| BLE device        | 4    | 2  |
| BLE beacon        | 6    | 3  |
| tracker candidate | 20   | 10 |

---

## Stage 4 - Gremlin Mode

USB interaction stage.

Abilities:

* safe HID awareness demos
* mission system
* host recognition

Food sources:

| Event            | Food | XP |
| ---------------- | ---- | -- |
| USB connect      | 5    | 2  |
| mission complete | 15   | 5  |
| trusted host     | 10   | 4  |

---

## Stage 5 - Sentinel

Guardian stage.

Abilities:

* anomaly detection
* rogue network alerts
* tracker warnings

Food sources:

| Event          | Food | XP |
| -------------- | ---- | -- |
| duplicate SSID | 25   | 12 |
| open network   | 10   | 5  |
| suspicious BLE | 20   | 10 |

# 6. Pet Stat System

Each pet has internal stats.

| Stat     | Range     | Description                   |
| -------- | --------- | ----------------------------- |
| Hunger   | 0-100     | decreases over time           |
| Mood     | 0-100     | happiness                     |
| Energy   | 0-100     | patrol ability                |
| XP       | unlimited | growth                        |
| Trust    | 0-100     | known environment familiarity |
| Mischief | 0-100     | gremlin behavior              |
| Health   | 0-100     | overall well-being            |

---

# 7. Personality Traits

Each pet receives **two random traits at hatch**.

Possible traits:

| Trait      | Effect                        |
| ---------- | ----------------------------- |
| Curious    | bonus XP for discoveries      |
| Protective | bonus guardian XP             |
| Chaotic    | gremlin missions trigger more |
| Sleepy     | energy drains slower          |
| Greedy     | requires more food            |
| Brave      | alert reactions faster        |

Traits influence behavior and animations.

---

# 8. Event System

The firmware runs an event-driven architecture.

Core events:

```
EVENT_USB_CONNECTED
EVENT_USB_DISCONNECTED
EVENT_WIFI_SCAN_DONE
EVENT_WIFI_DUPLICATE_SSID
EVENT_WIFI_OPEN_NETWORK
EVENT_BLE_DEVICE_FOUND
EVENT_BLE_TRACKER_ALERT
EVENT_BUTTON_SHORT
EVENT_BUTTON_LONG
EVENT_MISSION_COMPLETE
EVENT_TIMER_TICK
```

Events feed into the **rules engine**.

---

# 9. Rules Engine

Rules convert events into stat changes.

Example:

```
WiFi networks discovered = food gain
Duplicate SSID = guardian XP + alert
USB connect = trust increase
Mission completed = mischief increase
```

The rules engine maintains balance between recon, gremlin, and guardian behaviors.

---

# 10. Patrol System

Patrol is the primary gameplay loop.

When activated:

1. run Wi-Fi scan
2. run BLE scan
3. analyze results
4. reward pet
5. log journal entry

Example result:

```
PATROL COMPLETE

WiFi: 6
BLE: 3
Open AP: 1

Food +19
XP +12
```

---

# 11. Mission System

Available in Gremlin Mode.

Mission examples:

* display USB security message
* open awareness page
* type security tip

Example output:

```
USB Awareness Mission

Completed successfully

XP +15
Food +8
```

---

# 12. Notification System

Notifications alert the user.

Three tiers exist.

| Level    | Trigger             | Behavior   |
| -------- | ------------------- | ---------- |
| Info     | discovery           | blue LED   |
| Warning  | suspicious activity | yellow LED |
| Critical | confirmed anomaly   | red LED    |

Example alert:

```
ALERT

Duplicate SSID
CoffeeShop_WiFi
```
